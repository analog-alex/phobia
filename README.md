# Phobia

A short browser FPS set during a containment breach at Aether Labs. Built around fast movement, low-poly sci-fi horror, infected combat, and adaptive graphics.

## Stack

- [Bun](https://bun.sh/) - package manager and runtime
- [Babylon.js](https://www.babylonjs.com/) - 3D engine
- [TypeScript](https://www.typescriptlang.org/) - game code
- [Vite](https://vite.dev/) - development server and production build

## Run

```bash
bun install
bun run dev
```

Production build:

```bash
bun test
bun run build
```

## Controls

`WASD` move, `Shift` sprint, `Space` jump, mouse aim/fire, `R` reload, `E` interact, `Esc` pause, `F3` diagnostics.
